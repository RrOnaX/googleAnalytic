### Работа 11.09 — Анализ e-Com воронки + настройка GA4

**Что делал:**
- Разобрал 6 этапов e-Com воронки в фэшн-ритейле: заход → просмотр карточки → корзина → чекаут → ввод данных → оплата.
- Собрал инсайты рынка (Data Insight, RetailCRM/ЮKassa, vc.ru/Хабр).
- Разобрал кейсы: возврат брошенных корзин (RetailCRM) и сквозная аналитика (ContextLab).
- Сформулировал 3 гипотезы оптимизации: H1 — кнопка «В избранное», H2 — WhatsApp-триггер через 30 мин, H3 — калькулятор доставки в карточке.
- Настроил учебный ресурс GA4 (`Магазин Одежды (Тест)`, Measurement ID `G-7B2EX8W9LK`).

**Что понял:** воронка — это конкретные шаги с конкретными потерями. Больше всего теряется на корзине (30% брошенных в fashion) и на чекауте (до 90% трафика из-за UX). Гипотезы проверяются метриками, а не «на глаз».

### UTM-маркировка и сквозное отслеживание

**Что делал:**
- Разобрал анатомию URL и линейку UTM-параметров (`utm_source`, `utm_medium`, `utm_campaign`, `utm_term`, `utm_content`).
- Выучил 6 золотых правил разметки: латиница в нижнем регистре, `_` вместо пробелов, фиксированный список `utm_medium`, повод+период в кампании и др.
- Разобрал типичные ошибки: двойной `?` (`?a=1?b=2`) и метки после `#` (игнорируются скриптом аналитики).
- Реализовал метод «Первого касания» (First Touch).

**Что понял:** без UTM-меток трафик падает в `Direct (not set)`. Любая мелочь — регистр букв, лишний `?` — ломает группировку в отчётах. Разметка должна быть по единому справочнику.

**Что делал:**
- Сверстал многостраничный сайт (`index.html`, `about.html`, `contacts.html`) на HTML/CSS/JS в VS Code.
- Залил код на GitHub (`RrOnaX/ga4-analytics-lab-vlasyan`).
- Задеплоил на Vercel: https://ga4-analytics-lab-vlasyan.vercel.app
- Внедрил Google Tag (gtag.js) в `head` всех страниц.
- Проверил события `page_view`, `scroll`, `user_engagement`, `first_visit`, `session_start` в Realtime.

**Что понял:** аналитика работает только после реальной интеграции тега. Проверка в Realtime — обязательный шаг: без неё не видно, доходят ли события. Цикл «правка → деплой на Vercel → проверка» делает работу быстрой.

## 💡 Итог: что я понял, пройдя эти ДЗ

- **Аналитика — это система, а не один инструмент.** GA4, UTM, таблица лидов и Apps Script работают только вместе: сайт отправляет событие → GA4 его фиксирует → UTM объясняет источник → таблица принимает заявку → сквозная аналитика связывает источник с лидом.
- **Дьявол в настройках.** Часовой пояс, валюта, регистр букв в UTM, права доступа Web App — любая мелочь ломает отчёты или приём данных.
- **Без проверки в Realtime и тестовой заявки работа не считается сделанной.** Нужно своими глазами увидеть, что событие дошло и лид записался.
- **Гипотезы проверяются метриками.** Не «кажется, что кнопка поможет», а конкретные `add_to_wishlist`, CR корзины, `purchase` с канала.
- **Ошибки — часть работы.** 403 Forbidden показал, что не всё решается «по инструкции»: иногда нужно разбираться с правами доступа и CORS.
