# GA4 Lab: Учебная лаборатория веб-аналитики

**Автор:** Власян Давит
**Дисциплина:** Информационные технологии (ИТ)
**Тема:** Создание сайта и интеграция с Google Analytics 4 (GA4)

## 📌 О проекте
Данный проект представляет собой учебный многостраничный сайт (Home, About, Contacts), созданный для демонстрации навыков веб-разработки и настройки веб-аналитики. 

В ходе работы был пройден полный цикл разработки: от написания HTML/CSS/JS кода до публикации в интернете и сбора данных о поведении пользователей с помощью Google Tag (gtag.js) и GA4.

## 🚀 Выполненные задачи (Что я сделал)

1. **Разработка сайта (Frontend):**
   - Создана структура сайта из 3-х страниц (`index.html`, `about.html`, `contacts.html`).
   - Написан адаптивный и современный дизайн с использованием CSS (`style.css`).
   - Написан клиентский скрипт (`script.js`) для интерактивности.

2. **Верстка и код (VS Code):**
   - Работа выполнялась в редакторе кода VS Code.
   - Реализована верстка главной страницы с блоками: "Откуда пришли", "Что посмотрели", "Что сделали".

3. **Контроль версий (GitHub):**
   - Настроен Git-репозиторий для отслеживания изменений.
   - Код загружен на GitHub под именем `RrOnAx` (репозиторий `ga4-analytics-lab-vlasyan`).

4. **Публикация (Vercel):**
   - Проект успешно задеплоен на платформу Vercel.
   - Рабочий сайт доступен по публичной ссылке: [https://ga4-analytics-lab-vlasyan.vercel.app](https://ga4-analytics-lab-vlasyan.vercel.app) (откроется на телефоне/ПК).
   - Настроен автоматический деплой при пуше изменений в ветку `main`.

5. **Веб-аналитика (Google Analytics 4):**
   - Создан аккаунт и ресурс в GA4.
   - В `head` секцию всех страниц (начиная с `index.html`) внедрен **Google Tag (gtag.js)** с уникальным ID потока данных.
   - Настроен сбор событий (Events): `page_view`, `scroll`, `user_engagement`, `first_visit`, `session_start`.
   - Проверены данные в режиме реального времени (Realtime) и в отчетах (Просмотры, События).
   - Реализована передача UTM-меток для отслеживания источников трафика.

## 🛠 Стек технологий
* **HTML5** — семантическая верстка
* **CSS3** — стилизация, сетки (Grid/Flexbox)
* **JavaScript** — базовая интерактивность
* **Git & GitHub** — версионирование
* **Vercel** — хостинг и деплой
* **Google Analytics 4** — веб-аналитика
