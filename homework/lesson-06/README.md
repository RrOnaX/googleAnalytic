**Что нужно сделать для завершения Шага 8:**
1. Выделить столбец **A** (кликнуть на букву `A`).
2. Открыть: **Формат → Условное форматирование**.
3. Нажать **«+ Добавить правило»**.
4. Выбрать условие **«Ваша формула»**.
5. Вставить формулу: `=AND($A2<>"";COUNTIF($A$2:$A$1000;$A2)>1)`

7. Нажать **«Готово»**.
