## Текущий статус и причина остановки

Работа была приостановлена на **Шаге 8а** (настройка второго правила условного форматирования для подсветки дублей `request_id`).

**Причина остановки:**
При попытке отправить тестовую заявку с сайта (Иван, test@example.com, Frontend) в таблицу, Google Apps Script возвращает ошибку **403 Forbidden**. Это связано с настройками доступа при развертывании (Web App). Несмотря на то, что в настройках было выбрано «Все» (Anyone), скрипт всё равно отклоняет запрос.

В связи с этим дальнейшее тестирование (Шаги 27–33: проверка записи, дубли, статусы) временно невозможно. Работа требует дополнительной диагностики прав доступа или настройки CORS.

**Приношу извинения за вынужденную остановку. Работа будет продолжена после устранения ошибки 403.**
