# Маркировка трафика с помощью UTM-меток и сквозное отслеживание

Репозиторий содержит материалы практической работы по дисциплине **«Информационные технологии»** (Занятие №2): методология разметки входящего трафика, правила построения URL-адресов со строкой запроса и алгоритмы передачи данных об источниках переходов в системы аналитики и CRM.

---

## Часть 1. Теоретические основы разметки трафика

### 1. Проблема автоматического определения источника
Браузер не передает маркетинговый контекст перехода (факт рекламной кампании, конкретное объявление) по умолчанию. Стандартный HTTP-заголовок `Referer` часто пропадает при переходах из мессенджеров, документов или мобильных приложений, из-за чего в аналитике раздувается канал **Direct (not set)**. Решение — ручная или автоматическая предварительная запись параметров источника в URL.

### 2. Анатомия URL-ссылки (по стандарту RFC 3986)
* **https://** — Схема (протокол взаимодействия).
* **kolledzh.ru** — Узел (доменное имя машины).
* **/kursy** — Путь к конкретному ресурсу.
* **?utm_source=vk&...** — Строка запроса (довесок формата `имя=значение`, начинающийся с одного знака `?` и разделяемый знаками `&`).
* **#fragment** — Якорь/фрагмент для навигации внутри страницы. Не отправляется на сервер и не обрабатывается счетчиками аналитики.

### 3. Классическая линейка UTM-параметров
1. **`utm_source`** (Обязательный): Площадка, где размещена ссылка (например: `vk`, `priem_email`, `afisha_qr`).
2. **`utm_medium`** (Обязательный): Тип канала / способ доставки ссылки (`social`, `email`, `cpc`, `referral`, `organic`, `affiliate`).
3. **`utm_campaign`** (Обязательный): Маркетинговый повод / конкретная кампания (`sept_open_2026`).
4. **`utm_term`**: Ключевое слово (для контекстной рекламы).
5. **`utm_content`**: Дополнительная информация для различения похожих ссылок в одном креативе.

## Часть 2. Свод правил и типичные ошибки разметки

### 6 Золотых правил единого справочника меток:
1. **Только строчные латинские буквы** (VK и vk — разные строки для группировки в аналитике).
2. **Только латиница** (кириллица кодируется громоздким процентным кодом `%D0%...`).
3. **Символ подчеркивания `_` вместо пробелов** (пробелы превращаются в `%20` или `+`, размывая отчеты).
4. **Фиксированный список для `utm_medium`** (шаг влево — и трафик падает в категорию *Unassigned*).
5. **Повод + период в названии кампании** (например, `sept_open_2026` вместо абстрактного `test` или `dod`).
6. **Сборка строго по справочнику группы** перед публикацией.

### Технические уязвимости сборки адреса:
* **Дублирование знака вопроса:** Использование структуры вида `?a=1?b=2` вместо `?a=1&b=2` склеивает параметры.
* **Метки после знака `#`:** Скрипт аналитики считывает параметры из `location.search` (строка запроса до решётки). Все, что написано после фрагмента `#`, игнорируется, возвращая источник `(not set)`.
