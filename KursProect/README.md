# ЛапаДок — Ветеринарная клиника

**Сайт на Vercel:** https://lapadok-site.vercel.app
**Репозиторий GitHub:** https://github.com/RrOnaX/lapadok-site

## О проекте
Сайт ветеринарной клиники «ЛапаДок» с круглосуточной записью, калькулятором прививок и интеграцией соцсетей. Проект выполнен по техническому заданию ТЗ-06/2026.

## Что реализовано (Раздел 3)
- 8 страниц + 404.html (index, services, doctors, vaccines, pet-kit, contacts, thanks, privacy).
- Адаптивная вёрстка (корректно отображается на 375px, 768px и 1280px).
- Единая шапка с выделением активного пункта меню и круглосуточным телефоном.
- Форма записи с валидацией, чекбоксом согласия на обработку данных (152-ФЗ) и скрытыми полями UTM.
- Калькулятор прививок для кошек, собак и кроликов.
- Страница «Аптечка» с промокодом VACKINA (работает копирование в буфер обмена).
- Заготовка для аналитики `js/analytics.js` (события навешаны через `data-event`).
